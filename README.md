# 📌 CRUD – Projeto do 2º Semestre

Este projeto foi desenvolvido durante o **segundo semestre da faculdade**, com o objetivo de consolidar os conceitos fundamentais de **CRUD (Create, Read, Update, Delete)** utilizando **PHP** e **banco de dados real**, além de praticar a **execução e gerenciamento do sistema em um servidor local**.

---

## 🎯 Objetivo do Projeto

O foco principal deste semestre foi:

* Compreender o funcionamento completo de um CRUD
* Realizar a **leitura e manipulação de dados em um banco de dados real**
* Implementar regras básicas de negócio
* Estruturar um sistema funcional rodando em ambiente local

Para isso, o grupo definiu como produto principal uma **plataforma de venda e gerenciamento de ingressos**.

---

## 🛠️ Funcionalidades Implementadas

O sistema conta atualmente com as seguintes funcionalidades:

### 🎫 Ingressos

* Cadastro de ingressos
* Listagem de ingressos
* Edição de ingressos
* Exclusão de ingressos

### 🗂️ Categorias

* Criação de categorias
* Gerenciamento e organização dos ingressos por categoria

### 👤 Administradores

* Cadastro de administradores
* Controle de acesso administrativo

---

## 💻 Tecnologias Utilizadas

* **PHP**
* **MySQL** (banco de dados)
* **Servidor local** ( XAMPP )
* **HTML / CSS** para a interface

---

## 🚀 Próximos Passos

No próximo semestre, o projeto será expandido para incluir funcionalidades de **e-commerce**, tais como:

* Carrinho de compras
* Lista e gerenciamento de pedidos
* Integração com métodos de pagamento
* Fluxo completo de compra de ingressos

---

## 📚 Aprendizados

Este projeto foi essencial para o aprendizado prático de:

* Operações CRUD na prática
* Integração entre PHP e banco de dados
* Organização de um sistema web funcional
* Base para evolução futura em sistemas de e-commerce
